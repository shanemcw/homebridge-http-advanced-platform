# Development build acceptance - October 13, 2026

A development build was evaluated in a backed-up test installation before public
beta preparation. Package publication and repository changes were separate steps.

## Build and scope

The build included cross-origin redirect header hardening, the platform schema
correction, legacy accessory editors and heading/field/button capitalization.
Individual-command handling remained planned.

The installed archive matched the reviewed source. Installation preserved the
configuration, storage and pairing data. A deliberate restart loaded the
runtime; later UI-only corrections did not require another runtime restart.

## Validation

- Installed distributable files matched the final reviewed archive.
- Startup, getter restoration, state persistence and configuration preservation
  passed, with cached accessory and characteristic identities retained.
- Plugin Config displayed the editors, title-case headings and buttons, and
  sentence-case field labels. The read-only UI check did not save configuration.
- No plugin errors appeared in the inspected startup log window.
- User-reported state display and physical control passed; this was field
  acceptance rather than an independent observation by the release tooling.

## Rollback guidance

Retain a full backup and the exact previous package. For a full rollback, stop
Homebridge and restore through the installation's established backup workflow.
For a package-only rollback, reinstall the reviewed previous package and restart.
Check subsequent configuration edits before restoring; do not clear pairing or
cached accessories as a shortcut.
